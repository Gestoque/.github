## Gestoque

Software and field services for retail operations in Brazil. We run physical inventory counts for retailers and build the systems that let them do it themselves.

### Products

**[Gestoque](https://gestoque.com.br)** — inventory management platform. Retailers can hire our team to count their stores or run their own inventories with the system, using **G-Collector**, our offline Android collector app. Integrates with ERPs (SQL Server, MySQL, PostgreSQL, REST APIs).

**GesPlay** — digital signage for Android TV. Launched in October 2026 and already managing the content of the TVs in every store of one of Brazil's largest home textile retail chains.

### Public repositories

- [gcollector-releases](https://github.com/Gestoque/gcollector-releases) — release builds of the G-Collector Android app
- [integrity-api](https://github.com/Gestoque/integrity-api) — Google Play Integrity token validation API (Node.js, OpenAPI 3.1)
